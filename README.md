# Serendipity — 酒馆插件（剧情记忆 + 屏蔽词）

SillyTavern 第三方扩展：自动剧情记忆总结，以及剧情屏蔽词过滤。主按钮可拖动，面板为实色白。

## 功能

### 记忆
- 每轮对话（AI 生成回复）结束后，自动调用当前模型做一次「安静总结」。
- 总结字段：时间（年/月/日 周几 几时几分）、天气、在场人物、关键事件、角色与用户衣着、物品、约定/承诺、已完成约定、本段详细总结。
- 记忆**只叠加、不覆盖**：除非你在面板里手动点「删除」，否则插件不会删除任何记忆内容。
- 可手动点「立即总结」触发一次。

### 屏蔽词
- 输入屏蔽词（如「极其」）后立即把剧情与状态栏里所有该词眼替换为 ████。
- 只在界面显示层生效，不会改动聊天数据。
- 关闭屏蔽开关后，刷新页面可恢复原文。

## 安装

1. 酒馆「扩展 → 安装扩展（Install Extension）」粘贴本仓库 URL 安装。
2. 扩展列表勾选 **Serendipity** 启用，刷新。

或手动复制本目录到 `public/scripts/extensions/third-party/serendipity/`，重启。

## 说明

- 记忆总结每次会额外调用一次模型，消耗少量额度（这是「自动总结」的正常开销）。
- 记忆存于酒馆设置（浏览器本地存储），长期大量累积可能接近存储上限；如需长期使用建议定期手动整理（仅手动删除）。
