# Serendipity — 酒馆插件（剧情记忆 + 屏蔽词 + 指令）

SillyTavern 第三方扩展：自动剧情记忆总结、剧情屏蔽词过滤、以及指令系统。主按钮可拖动，面板为实色白，整插件按角色卡绑定。

## 功能

### 记忆
- 每轮对话（AI 生成回复）结束后，自动调用当前模型做一次「安静总结」。
- 总结字段：时间（年/月/日 周几 几时几分）、天气、在场人物、地点、关键事件、角色与用户衣着、物品、约定/承诺、已完成约定、本段详细总结。
- 三档记忆，自动晋级：
  - **短期记忆**：每轮的详细总结，满 10 条后合并成一条写入 **长期记忆**，并清空短期。
  - **长期记忆**：满 10 条后合并成一条写入 **永久记忆**，并清空长期。
  - **永久记忆**：只增不删，永不自动删除。
- **长期记忆与永久记忆可折叠**（默认收起），短期记忆置顶、默认展开，方便快速查看最近的剧情。
- 记忆**只叠加、不覆盖**：除你在面板里手动点「删除」外，插件不会删除记忆（永久记忆连删除按钮都没有）。
- 记忆会被**注入正文 prompt**，生成时模型会读取并延续之前的设定与情节，防止失忆、避免前后矛盾。
- 可手动点「立即总结」触发一次，也可点「导出」把全部记忆下载为 .txt 文件。

### 屏蔽词
- 输入屏蔽词（如「极其」）后立即把剧情与状态栏里所有该词眼**直接删除**。
- 屏蔽词同时被**注入正文 prompt**，明确要求模型不得再输出这些词，从根本上防止该词反复出现。
- 界面显示层删除不会改动聊天数据，关闭屏蔽后刷新页面可恢复原文。

### 指令
- 指令**数量不限**，可随时添加、删除；每条指令自带独立开关，可单独开启/关闭。
- 已开启的指令每轮生成都会注入正文 prompt，模型每轮都会读取并遵守。

### 角色卡绑定
- 整插件（记忆、屏蔽词、指令）**按角色卡绑定**：换到新角色卡时插件是干净的一套，切回旧角色卡则恢复该角色卡自己的记忆/屏蔽词/指令，互不串扰。

## 安装

1. 酒馆「扩展 → 安装扩展（Install Extension）」粘贴本仓库 URL 安装：
   ```
   https://github.com/lit66731-star/st-serendipity
   ```
   注意：只粘贴上面这一行 URL，不要带空格、引号、换行或句尾标点，否则会报 `Bad Request` 安装失败。
2. 扩展列表勾选 **Serendipity** 启用，刷新。

或手动复制本目录到 `public/scripts/extensions/third-party/serendipity/`，重启。

## 说明

- 记忆总结每次会额外调用一次模型，消耗少量额度（这是「自动总结」的正常开销）。
- 记忆存于酒馆设置（浏览器本地存储），长期大量累积可能接近存储上限。
